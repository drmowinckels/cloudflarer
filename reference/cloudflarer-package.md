# cloudflarer: Interface to the Cloudflare API

An R interface to the Cloudflare REST API
(<https://developers.cloudflare.com/api/>). Wraps the v4 API with
authenticated requests, response unwrapping, paginated list helpers, and
a generic request function so users can call any endpoint that is not
yet covered by a dedicated wrapper.
